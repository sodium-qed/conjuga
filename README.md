# Conjuga

A browser-based Spanish verb conjugation practice app. Choose a tense and practice regular and irregular verbs, reflexive forms, verbs like *gustar*, and progressive forms. The interface is in Spanish.

## Get started

1. Download [`conjugation_practice.html`](conjugation_practice.html) from this repository.
2. Open the downloaded file in a modern web browser.
3. Choose a mode and tense, then type the conjugated form and press Enter. Accents matter; on-screen accent buttons are available.

Use the optional **vosotros** and reflexive settings to tailor practice, or start the timed 32-question challenge. The page tracks points, level and streaks. Total points are saved in the browser's local storage; clearing site data or resetting progress removes them.

Conjuga is a single HTML file with its scripts and styles included. It does not require an account, installation or an API key.
